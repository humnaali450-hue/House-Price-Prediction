  #House Price Prediction Using Linear Regression

## 📌 Project Overview
This project predicts house prices using Machine Learning.  
A Linear Regression model is trained on house features such as number of rooms, size, location, and age to estimate the selling price.

The goal is to understand regression analysis and apply Python with Scikit-learn for real-world prediction tasks.

---

## 🎯 Objectives
- Learn regression analysis
- Understand supervised learning
- Implement Linear Regression using Scikit-learn
- Train and evaluate ML models
- Make predictions on new data

---

## 📊 Dataset Features

| Feature | Description |
|---------|-------------|
| Rooms | Number of rooms in the house |
| Size | Size in square feet |
| Location | Location score (1–5) |
| Age | Age of the house (years) |
| Price | Target house price |

Dummy dataset is created inside the Python script.

---

## ⚙️ Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- VS Code

---

## 🧠 Machine Learning Workflow
1. Data creation
2. Feature selection
3. Train-test split
4. Linear Regression model training
5. Model evaluation (MSE, R² Score)
6. Prediction for new houses
